## 🚀 Как запустить локально
1.  Склонируй репозиторий:
    ```bash
    git clone https://github.com/Zheny179/Figma-Land.git
    ```
3.  Перейдите в папку проекта (папка Figma-Land)
4.  Откройте файл *index.html* в браузере
